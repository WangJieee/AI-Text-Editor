# AI Text Editor (Next.js + Rust Fullstack App)

---

## 🚀 Live Deployment

[ai-editor-pearl.vercel.app](https://ai-editor-pearl.vercel.app/)

---

## ✨ Functionality

This app features an AI-powered text editor that helps you improve your writing with the following capabilities:

- **Paraphrasing:** Select any text and let the AI rewrite it in a different way while keeping the original meaning.
- **Expanding:** Select text and ask the AI to elaborate, adding more detail and depth.
- **Summarising:** Select text and have the AI generate a concise summary.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn]
- [Rust](https://www.rust-lang.org/tools/install)

---

## 1. Install Dependencies

### Frontend (Next.js)

```bash
npm install
# or
yarn install
```

### Backend (Rust)

```bash
cargo build
```

---

## 2. Build the App

### Frontend (Next.js)

```bash
npm run build
# or
yarn build
```

### Backend (Rust)

```bash
cargo build --release
```

---

## 3. Develop the Fullstack App

```bash
vercel dev
```

Access development on http://localhost:3000

---

## 4. Production deployment

```bash
vercel deploy
```
